## antislop
For UI, copy, people, mobile layout, or code comments work, read `.agents/plugins/antislop/antislop.md` (core) and then the skill for the task:

- UI / visual: `.agents/plugins/antislop/skills/antislop-ui/SKILL.md`
- Copy & text: `.agents/plugins/antislop/skills/antislop-copywriting/SKILL.md`
- People / accessibility: `.agents/plugins/antislop/skills/antislop-human/SKILL.md`
- Mobile / responsive: `.agents/plugins/antislop/skills/antislop-layoutmobile/SKILL.md`
- Code comments & cleanliness: `.agents/plugins/antislop/skills/antislop-code/SKILL.md`

Before starting, follow the core's "Two Usage Modes" section: explicit session instruction first, then global preference, then ask. For a resolved mode, announce `antislop active: <mode> (session override).` or `antislop active: <mode> (global preference).` once, using the actual mode and source.
